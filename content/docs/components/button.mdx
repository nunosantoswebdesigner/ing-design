## Variants

Six visual styles for different contexts and hierarchy levels.

<div className="flex flex-wrap gap-3 items-center my-6">
  <Button variant="default">Default</Button>
  <Button variant="secondary">Secondary</Button>
  <Button variant="outline">Outline</Button>
  <Button variant="ghost">Ghost</Button>
  <Button variant="destructive">Destructive</Button>
  <Button variant="link">Link</Button>
</div>

## Sizes

Four general sizes plus three icon-only sizes.

<div className="flex flex-wrap gap-3 items-center my-6">
  <Button size="sm">Small</Button>
  <Button size="default">Default</Button>
  <Button size="lg">Large</Button>
  <Button size="icon">
    <MailIcon />
  </Button>
  <Button size="icon-sm">
    <MailIcon />
  </Button>
  <Button size="icon-lg">
    <MailIcon />
  </Button>
</div>

## With Icon

Icons are sized automatically via `[&_svg]:size-4`.

<div className="flex flex-wrap gap-3 items-center my-6">
  <Button>
    <MailIcon />
    Send email
  </Button>
  <Button variant="outline">
    Continue <ArrowRightIcon />
  </Button>
</div>

## Loading

Swap the icon for a spinner. Disable the button to prevent repeated submissions.

<div className="flex flex-wrap gap-3 items-center my-6">
  <Button disabled>
    <Loader2Icon className="animate-spin" />
    Saving…
  </Button>
  <Button variant="outline" disabled>
    <Loader2Icon className="animate-spin" />
    Loading
  </Button>
</div>

## As Child

Use `asChild` to render the button styles on a different element.

<div className="my-6">
  <Button asChild>
    <a href="#">Go to docs</a>
  </Button>
</div>

## Props

| Prop        | Type                                                                          | Default     | Description                          |
| ----------- | ----------------------------------------------------------------------------- | ----------- | ------------------------------------ |
| `variant`   | `"default" \| "secondary" \| "outline" \| "ghost" \| "destructive" \| "link"` | `"default"` | Visual style                         |
| `size`      | `"default" \| "sm" \| "lg" \| "icon" \| "icon-sm" \| "icon-lg"`               | `"default"` | Size of the button                   |
| `asChild`   | `boolean`                                                                     | `false`     | Renders children as the root element |
| `className` | `string`                                                                      | —           | Additional CSS classes               |

## Usage

```tsx
import { Button } from "@/components/ui/button";
import { MailIcon } from "lucide-react";

// Default
<Button>Click me</Button>

// Variant
<Button variant="outline">Cancel</Button>

// Size
<Button size="lg">Get started</Button>

// With icon
<Button><MailIcon />Send email</Button>
```

## Specs

```md
# New York — Button Specs

## Component

- name: button
- file: registry/new-york/button.tsx
- installs to: components/ui/button.tsx
- dependencies: class-variance-authority, radix-ui

## What is it

A multipurpose action trigger. Use it to submit forms, navigate, or initiate
operations. Prefer Button over a link when the action changes state or triggers
a process. Avoid using more than one "default" variant in the same visual area.

## Visual identity

Neutral dark palette. Near-black primary conveys seriousness and clarity.
Standard border radius (0.625rem) gives a balanced, professional feel.
No colour bias — works across any content type or brand context.

## Design tokens

--primary: oklch(0.205 0 0) — near-black
--primary-foreground: oklch(0.985 0 0) — near-white
--secondary: oklch(0.97 0 0) — very light grey
--secondary-foreground: oklch(0.205 0 0)
--accent: oklch(0.97 0 0)
--accent-foreground: oklch(0.205 0 0)
--muted: oklch(0.97 0 0)
--muted-foreground: oklch(0.556 0 0) — mid grey
--destructive: oklch(0.577 0.245 27.325) — red
--border: oklch(0.922 0 0) — light grey
--ring: oklch(0.708 0 0) — medium grey focus ring
--radius: 0.625rem — balanced, slightly rounded

## Variants

- default → near-black fill. Primary CTA. High visual weight.
- secondary → light grey fill. Secondary action. Low visual weight.
- outline → transparent, grey border. Equal weight to secondary.
- ghost → no border, no fill. Tertiary action or toolbar button.
- destructive → red fill. Irreversible or dangerous actions only.
- link → text-only underline. Inline navigation or contextual actions.

## States

- hover: primary darkens slightly; outline/ghost shows tinted background
- focus: 3px ring in --ring colour (grey), offset 0
- disabled: opacity-50, pointer-events-none
- loading: Loader2Icon + animate-spin, always disable the button when loading

## Conventions

- One default variant per visual group maximum
- Pair default + outline for primary/secondary action pairs
- Pair default + ghost for toolbar actions
- Spacing between adjacent buttons: gap-2 (8px) minimum
- Icon-only buttons require aria-label
- SVG icons auto-size to 16px — do not override unless intentional
```

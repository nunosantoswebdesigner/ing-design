---
title: Libraries
description: External libraries used by ING Design components. Install these in your app as needed.
---

External libraries that components in this registry depend on or are designed to work with. Install them in your project when using the relevant components.

- **[Radix UI](https://www.radix-ui.com)** — Headless UI primitives. All components are built on Radix — it handles accessibility, keyboard navigation, and ARIA automatically.

- **[Sonner](https://sonner.emilkowal.ski)** — Toast notifications. Used by any component that triggers user feedback messages.

- **[Chart.js](https://www.chartjs.org)** — Chart and data visualisation library. Used by chart-related components.
